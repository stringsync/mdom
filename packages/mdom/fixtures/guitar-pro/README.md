# Guitar Pro fixtures

These unmodified Guitar Pro 7 fixtures come from alphaTab's test corpus:
https://github.com/CoderLine/alphaTab/tree/1f428ccd1ea2faeeb1a8b48cb17194cfd60ba11e/packages/alphatab/test-data/guitarpro7

Upstream commit: `1f428ccd1ea2faeeb1a8b48cb17194cfd60ba11e`. Copyright Daniel Kuschny and contributors.
The upstream MPL-2.0 license is included as `LICENSE.alphatab`.

The files are committed so `mdom test` runs offline. They exercise the reader
independently of mdom's writer. Export tests inspect the generated GPIF XML,
and round-trip tests cover the musical values across both conversions.

The `.gpx` files are unmodified Guitar Pro 6 fixtures from the same commit's
`packages/alphatab/test-data/guitarpro6` directory (`notes`, `strings`,
`time-signatures`, `key-signatures`, `tuplets`, `grace`, `repeat-close` and
`score-info`). Their GPIF reads through the same reader as GP7/8 with no
changes, and tests compare them with the GP7 fixtures of the same name.

The `.gp5` files are unmodified Guitar Pro 5 fixtures from the same commit's
`packages/alphatab/test-data/guitarpro5` directory (`notes`, `strings`,
`time-signatures`, `key-signatures`, `tuplets`, `grace`, `repeat-close` and
`score-info`). Tests compare them with the GP7 fixtures of the same name where
the two files hold the same score; `time-signatures.gp5` stores its default
dynamic and a bar's trailing rest differently from its GP7 counterpart.

The same directory supplies `bends`, `dead`, `directions`, `effects`, `hammer`,
`harmonics`, `chords`, `ottavia`, `slides`, `strokes`, `tremolo`, `vibrato`,
`repeat-close-alternate-endings` and `beat-text-lyrics` as `.gp5`, which tests
compare with the GP7 file of the same name (`directions.gp` is Guitar Pro 8).

The `.gp3` and `.gp4` files are unmodified Guitar Pro 3 and 4 fixtures from the
same commit's `packages/alphatab/test-data/guitarpro3` and `guitarpro4`
directories (`notes`, `strings`, `dead`, `grace`, `vibrato`, `time-signatures`,
`score-info` and `effects` in both; `tuplets`, `hammer`, `slides`, `strokes`,
`bends`, `tremolo` and `harmonics` as `.gp4`). Tests compare them with the GP7 or
GP5 file of the same name; the older formats lack effects later versions added,
such as GP3's per-note vibrato and pick strokes and GP4's ottavas.

`hide-tuning.gp` comes from the same commit's
`packages/alphatab/test-data/guitarpro8` directory and covers a GP8 empty bar.

These unmodified files from the same commit back the Guitar Pro coverage
scoreboard (`packages/e2e/guitar-pro-coverage.test.ts`) and give each feature
still missing an import fixture: from `guitarpro7`, `bends`, `harmonics`, `dead`,
`effects`, `hammer`, `slides`, `vibrato`, `beat-lyrics`, `lyrics-template`,
`repeat-close-alternate-endings`, `fermata`, `strokes`, `tremolo`, `ottavia`,
`chords` and `drum-tabs`; from `guitarpro8`, `directions` and
`beat-tempo-change`. `drum-tabs` also backs the percussion tests, and its kit,
Guitar Pro 7's standard one, is the table `guitar-pro-drum-kit.ts` exports.

`piano-playback.gpif` contains only the first track's AudioEngineState, Sounds,
and Automations nodes from alphaTab's
`packages/alphatab/test-data/guitarpro8/header-footer.gp` at the same pinned
commit above. It provides an independent native GP8 piano playback reference;
no score content is included. The accompanying alphaTab license also applies.

`piano-native.gp` is an original six-bar piano pitch-check score made for mdom.
It was exported with alphaTab 1.8.4, then its notation-only notes were given
native GPIF tuning/string/fret properties and the extra Octave/Tone properties
were removed. Jared confirmed the scale plays at distinct, correct pitches in
Guitar Pro 8 on September 7, 2026. It is a fixed compatibility reference, not
regenerated by tests. The score and these manual edits are under mdom's MIT
license.
